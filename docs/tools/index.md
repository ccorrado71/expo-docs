# Tools

The **Tools** menu of the structure viewer (JAV) collects several utilities to work on the
crystal structure model. This section describes:

- [Geometry optimization](geometry-optimization.md): optimization of the molecular
  geometry by molecular mechanics (**Tools → Optimize Geometry**) or MOPAC, and
  preparation of input files for DFT calculations
  (**Tools → Optimize Crystal Structure by DFT-D**), with the comparison between
  experimental and optimized structures (**Tools → Overlay Structures**,
  **Tools → Overlay Info**);
- [Bond valence sum](bond-valence.md): check of the bond valence sums of a structure
  (**Tools → Bond Valence Sum**).

The same menu also contains the tools to add hydrogen atoms (**Tools → Add Hydrogens**,
see [Tutorial 1](../tutorials.md#intensity-extraction-and-direct-methods)).
